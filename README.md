# Project 09 — Bank-Style Credit Risk Decisioning

This replaces the previous inventory concept with a substantially different, bank-style analytics project.

## What it demonstrates

- SME credit risk scorecard
- Probability of Default (PD)
- Exposure at Risk
- Loss Given Default (LGD)
- Expected Credit Loss (ECL)
- Risk segmentation
- Explainable decision thresholds
- Early-warning indicators
- Credit decision queue
- Portfolio concentration
- Stress-test thinking
- Model governance / human oversight
- Python/Pandas implementation
- Synthetic data only

## Important

This is a portfolio demonstration, not a real lending model. Thresholds and scores are illustrative. A production financial model requires validated data, model governance, fairness testing, regulatory review and human oversight.

## Run

```bash
pip install -r requirements.txt
python src/model_logic.py
```

Then open `index.html`.

## Why this is valuable commercially

The same architecture can be adapted for legitimate business analytics such as invoice-risk monitoring, customer payment-risk segmentation, cash-flow early warnings and operational risk dashboards without making actual lending decisions.
